# scraper - חיבור אוטומטי לבנקים

תיקייה זו היא שירות "צד" קטן ב-Node.js, נפרד מהשרת הראשי (שכתוב בפייתון),
שאחראי רק על דבר אחד: להתחבר לאתר הבנק/כרטיס האשראי (בדיוק כמו שאתם
מתחברים בדפדפן) ולקרוא ממנו יתרה ותנועות, בעזרת הספרייה הפתוחה
[israeli-bank-scrapers](https://github.com/eshaham/israeli-bank-scrapers).

כל זה קורה **מקומית על המחשב שלכם בלבד** - שום סיסמה או נתון לא נשלח
לשום שרת חיצוני. הבקאנד הפייתון פשוט מריץ תהליך Node קטן, שולח לו את
פרטי ההתחברות (שמפוענחים מהכספת המוצפנת רגע לפני כן), ומקבל בחזרה JSON
עם היתרה.

## התקנה חד-פעמית

צריך Node.js מותקן על המחשב (גרסה 18 ומעלה). לאחר מכן:

```bash
cd scraper
npm install
```

ההתקנה מורידה גם דפדפן Chromium מקומי (כמה מאות MB) שהספרייה משתמשת בו
כדי "להתחבר" לאתרי הבנקים - זה יכול לקחת כמה דקות בפעם הראשונה.

אם Node.js לא מותקן, או ש-`npm install` לא רץ - חלק "חיבור אוטומטי
לבנקים" באפליקציה יציג הודעה מתאימה, אבל שאר האפליקציה (כולל הזנת יתרות
ידנית לבתי השקעות/ביטוח, וכל מה שהיה קיים קודם) ימשיך לעבוד כרגיל.

## בדיקה ידנית

```bash
echo '{"companyId":"hapoalim","credentials":{"userCode":"...","password":"..."}}' | node scrape.js
```
